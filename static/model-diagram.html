🎯 How the Model Works

The full prediction pipeline — from raw feeds to a sized bet (or a disciplined "no bet")

Why market-first

  • • Backtest: pure Elo vs closing line = 51.1% ATS (1,359 games) — below the 52.4% breakeven
  • • So the de-vigged book consensus IS the base (85%)
  • • Elo (15%) = prior + sanity check + pre-lines mode
  • • The model only disagrees at the margins — and says "no bet" when the gap can't cover the vig

Adjustments: what survived backtesting

  • • ✅ Home fav 7+: 62.5% ATS (n=112) — angle badge
  • • ✅ Wind 15+ mph: 60.9% under (n=87) — totals model
  • • ✅ Wind 10-14: 57.9% under (n=178)
  • • ✅ Close spread ≤3: 57.5% under (n=518)
  • • 🔄 Rest edge INVERTED (rested teams 47%) → we fade
  • • ❌ Killed: divisional dogs (46.9%), TNF trends, body clock, cold-weather unders

Honesty plumbing

  • • Every ≥2 pt edge gets logged daily with timestamp (sides + totals)
  • • Graded against the closing line — the harsh, honest number
  • • Track Record shows W-L, profit, edge buckets, calibration
  • • If bigger edges don't win more, the model is noise — the page will show it
